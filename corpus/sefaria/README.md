# Sefaria: Hebrew Torah (frozen copy)

Raw, unmodified JSON files of the five books of the Torah used as the Hebrew target corpus (decipherment notebooks
and the re-analysis in `reanalysis/`). Downloaded 2026-10-29 from `https://storage.googleapis.com/sefaria-export/`,
path `json/Tanakh/Torah/{Book}/Hebrew/Tanach%20with%20Text%20Only.json` (the earlier
`raw.githubusercontent.com/Sefaria/Sefaria-Export` URLs stopped working in September 2026).
Licence (JSON `license` field): Public Domain (tanach.us / Westminster Leningrad Codex).

Targum Onkelos and the Zohar, also used, are not redistributed here; `reanalysis/fetch_external.sh` downloads them.
